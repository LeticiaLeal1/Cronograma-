O que é Criptografia de Letras?

A criptografia transforma informações para dificultar sua leitura por pessoas não autorizadas. Um método clássico é a Cifra de César, uma cifra de substituição.

Como funciona? Cada letra é deslocada três posições no alfabeto: A vira D, B vira E e C vira F. Ao chegar ao final do alfabeto, a contagem recomeça: X vira A, Y vira B e Z vira C.

Explicação do Código Desenvolvido

O JavaScript executa as seguintes etapas:

  • Captura o texto digitado com document.getElementById.
  • Percorre cada caractere usando um laço for.
  • Converte as letras em códigos numéricos e aplica o deslocamento de três posições.
  • Utiliza o operador módulo % 26 para reiniciar a contagem no começo do alfabeto.
  • Exibe o resultado na página com textContent.

Observação: a Cifra de César é um método didático e não deve ser utilizada para proteger informações confidenciais.
